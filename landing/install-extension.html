Install the browser extension

Five steps, about two minutes. This works in Microsoft Edge, Chrome and Brave. You need an Arevei Vault account first: the extension signs in to the vault you already created.

Download the extension (.zip) Add to Edge instead

On Edge, the store button is one click and updates itself. Use the steps below for Chrome and Brave.

  1. Download the zip.

    Use the button above. The file comes from the project's GitHub releases, where every version is listed with its checksum.

  2. Unzip it into a folder you will keep.

    For example Documents\Arevei Vault extension. The browser runs the extension from this folder, so don't leave it in Downloads and don't delete it later.

  3. Open the extensions page.

    Paste the address into the address bar: edge://extensions in Edge, chrome://extensions in Chrome, brave://extensions in Brave.

  4. Turn on Developer mode.

    In Edge the switch is in the left sidebar. In Chrome and Brave it is in the top-right corner.

  5. Click “Load unpacked” and pick the folder.

    Choose the folder from step 2, the one that contains manifest.json. Arevei Vault appears in the list. Pin it from the puzzle-piece menu, click its icon and sign in with your email, master password, Secret Key and two-factor code.

Good to know

  • You sign in once. The extension stays signed in and unlocked on this browser until you lock it or sign out. On a shared computer, set Auto-lock in the extension to a time.
  • Updates are manual. An extension installed this way does not update itself. To update, download the new zip, replace the files in the same folder, then press Reload on the extensions page.
  • The browser may warn you about developer mode when it starts. That is expected for an extension installed outside a store. Keep the extension enabled.
  • Your vault stays encrypted. The extension decrypts on your device, the same way the web vault does. We can't read it.
